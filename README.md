# TrainingLog

Личный дневник тренировок: https://cleargate.ru/training/

Реализованы локальный журнал, PWA и первый серверный инкремент: вход владельца, SQLite, синхронизация программ и сессий, явные конфликты и резервные копии. Весь исходный план ещё не завершён.

## Использование

1. Закройте старые окна дневника и откройте сайт, чтобы установить обновлённую PWA.
2. В «Настройках» введите пароль владельца и нажмите «Войти и подключить синхронизацию». Первичный пароль передан владельцу отдельным локальным файлом, вне репозитория. Там же можно изменить пароль.
3. Программы и тренировки этого браузера синхронизируются с сервером; на другом устройстве войдите с тем же паролем. До входа можно работать локально.
4. Записывайте фактические веса и повторения. Дождитесь локального сохранения; серверный статус показывается отдельно. Без сети записи отправятся при следующем открытии с сетью.
5. При конфликте скачайте обе версии и явно выберите нужную. Отброшенный вариант также сохраняется в локальном архиве конфликтов.
6. На iPhone: Safari → Поделиться → На экран Домой. Дождитесь отметки офлайн-готовности.

Bro Split импортируется отдельной кнопкой и не заменяет существующий дневник. Пять шаблонов, 28 упражнений, 96 подходов; повторы по подходам, темп, пары суперсетов и исходные веса сохранены как цели/заметки. Исторические занятия из скриншотов не выдуманы.

«Для Любименькой ❤️» добавляется в разделе «Программы» → «Готовые программы» и сразу выбирается. Три дня: ноги/ягодицы, спина/плечи, руки/корпус; по шесть упражнений. Сохранены диапазоны повторений, RIR 1–3, отдых, двойная прогрессия и альтернативы в заметках. Выпады, Dead bug, Bird dog и Pallof press учитываются по сторонам. Веса заполняются по факту; для гакка, моста и Хаммера сначала выбирается оборудование. Повторный импорт не создаёт копию и не заменяет правки или историю. Программа в архиве/корзине восстанавливается через настройки.

## Реализовано

- Программы, дни, упражнения и режимы учёта веса; снимки программы в тренировках.
- Предложение следующего дня по завершённым занятиям, свободный выбор другого дня. Напоминания об отдыхе Bro Split после спины и плеч.
- Чередование подходов распознанных пар суперсетов из заметок Bro Split, переход к следующему подходу после подтверждения и восстановление порядка по сохранённым статусам.
- Копирование и перестановка дней, порядок упражнений в программе и активном занятии.
- Замена упражнения только на сегодня: выбор из программ или ручной ввод. При наличии любых записей исходное упражнение сохраняется, замена добавляется рядом.
- Русские названия всех 28 упражнений Bro Split, 56 локальных фото и краткие подсказки. Фото открываются в блоке «Как выполнять» и сохраняются офлайн; различия с исходным вариантом подписаны. Старые английские названия отображаются по-русски без изменения записей.
- Мобильный интерфейс для iPhone 16 Pro Max: safe-area, поля 16 px, кнопки от 44 px, нижняя навигация в обеих ориентациях и компактный экран активного занятия.
- Вес в целых граммах; черновики, рабочие/разминочные подходы, RIR и заметки.
- Подтверждение, исправление в активной сессии, пропуск, завершение и отмена.
- История, предыдущие сопоставимые результаты, восстановление активного занятия.
- Исправление завершённых записей с проверкой версии, сохранением даты и синхронизацией.
- Прогресс: вес при минимуме повторов, повторы при выбранном весе, рабочие подходы по неделям, рекорды за период. Вариант, оборудование и режим веса сравниваются отдельно.
- CSV всех подходов или тренировок за период; черновики не становятся подтверждёнными результатами.
- Таймер по абсолютному времени; JSON-экспорт и атомарное восстановление.
- IndexedDB v3 с сохранением старых данных и очереди, PWA без принудительного обновления во время занятия.
- Длительность и отдельные строки левой/правой стороны; сопоставимые графики и исправления истории.
- Каталог оборудования с индивидуальными шагами и нерегулярными делениями; кнопки веса и подстановка прошлых значений в черновик.
- Календарь отдыха, произвольные группы суперсетов и создание нескольких программ.
- Синхронизируемые архив и корзина с восстановлением, JSON v2 с каталогами; чтение старого JSON v1.
- OpenAPI 3.1, генерируемые DTO клиента, контракт записи v2 с защитой от старых клиентов.
- ASP.NET Core Identity: одна учётная запись, без регистрации, защищённые cookies, CSRF, ограничение входа.
- EF Core/SQLite, миграция, версии документов, неизменяемый журнал серверных изменений.
- Синхронизация полных снимков с operationId, базовой версией, повтором потерянных ответов, курсором и поколением базы.
- Показ конфликтов, сохранение обеих версий; две активные тренировки не заменяют друг друга молча.
- Ежедневные серверные копии и скачивание на компьютер владельца; тестовое восстановление в отдельный каталог.

## Запуск на Windows

Node.js 24 и .NET SDK из global.json. Docker/WSL не нужны. Для браузерных тестов установите WebKit: из apps/web выполните `npx playwright install webkit`; также используется установленный Edge.

```powershell
cd apps/web
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Vite проксирует `/training/api` на `127.0.0.1:5180`. Для локального API создайте приватный файл с собственным паролем от 12 символов (регистр, цифра, спецсимвол), затем:

```powershell
dotnet run --project apps/api --no-launch-profile -- --urls http://127.0.0.1:5180 --environment Development --DataDirectory C:/private/training-data --OwnerPasswordFile C:/private/training-password.txt
```

OwnerPasswordFile читается только при создании владельца. Не используйте тестовый пароль для рабочего сервера. Приложение и API в production доступны через HTTPS одного origin; сервис слушает только loopback.

## Проверки

`scripts/test.ps1`: unit/storage, браузерные сценарии, синхронизация двух устройств, build, offline, lint, API/xUnit. `npm run test:sync` сам запускает API с новой изолированной тестовой базой и отдельный Vite. Тестовые записи не отправляются на рабочий сервер.

Пройдено: 47 frontend unit/storage тестов; 22 браузерные проверки (11 сценариев в Edge и WebKit с профилем iPhone 16 Pro Max); сценарий двух устройств с секундами, сторонами, каталогами, конфликтом и корзиной; 9 API проверок. Офлайн-кэш проверяется отдельно на сборке и HTTPS. Тестовые тренировки создаются только в изолированных базах.

## Объём релиза и ограничения

Согласованный список оставшихся функций реализован. Инструкция по новым возможностям, модель, контракт и решения относительно исходного плана — в docs/release-v2.md. Исторические пункты раздела развёртывания описывают соответствующие старые выпуски.

Программы и справочники редактируются локально с последующей синхронизацией и разрешением конфликтов. Сервер хранит версионированные агрегаты и отдельные документы оборудования/календаря; снимки не каскадируют при удалении профиля. Восстановление JSON не удаляет серверные записи неявно. После восстановления нужно заново подключить синхронизацию; совпадающие UUID сверяются, различия требуют выбора.

Проверки на физическом iPhone и реальные тренировки исключены из этой работы владельцем. Эмуляция WebKit не заменяет их. Фоновая отправка из закрытого приложения не обещается. При выходе локальная база намеренно остаётся на устройстве. P2 исходной спецификации (замеры тела, внешние адаптеры, носимые устройства и дополнительные пользователи) остаётся отдельным необязательным backlog.
