# Поручение для запуска на Mac

Скопируй текст ниже в новую сессию, открытую в корне перенесённого проекта TrainingLog.

> Реализуй личное приложение Apple Watch по `docs/apple-watch-plan.md`. Сначала прочитай локальные инструкции проекта и этот план целиком, проверь текущий код и незакоммиченные изменения. Мои ограничения: платную Apple Developer Program оформить не могу и платить не хочу; используем только бесплатную Personal Team и установку из Xcode. App Store, TestFlight и платные сервисы не нужны. Я понимаю ограничение бесплатной подписи в 7 дней.
>
> Начни с этапа 0: проверь совместимость Mac/Xcode/iPhone/часов, создай минимальный watch-only target и проверь реальную установку через мой Apple Account, локальное сохранение и повторную установку поверх приложения. Мои часы предположительно Series 8 или 9 — выясни модель/версии на месте. Apple-пароль, 2FA и системные подтверждения я введу сам. Не записывай их в файлы и не покупай подписку. Если Personal Team не даёт подписать минимальное приложение, сначала разберись с точной ошибкой; не строй всю серверную интеграцию, считая установку уже решённой.
>
> После успешной проверки продолжай по плану: watchOS SwiftUI, локальная запись подходов без сети, подключение к нашему API, явная передача одной тренировки между PWA и часами, защищённая привязка, таймер через абсолютное время и локальные уведомления, сохранение очереди и восстановление конфликтов. Пульс/HealthKit, отдельное приложение iPhone, публикация и полностью автоматическая переподпись не входят в первую версию.
>
> Реализуй необходимые локальные изменения, проверь их на изолированной БД, подготовь установку на часы и инструкцию обновления подписи. Сохрани чужие изменения и мои данные. Рабочие данные на cleargate.ru не использовать для синтетических тестов. Выкладку изменений API/PWA на рабочий сервер подготовь к проверке; само развёртывание выполняй только после моей авторизации. Держи меня в курсе существенных результатов и оставшихся ограничений.

## Что перенести

- Актуальный репозиторий целиком, включая оба документа `docs/apple-watch-*.md`. Перед передачей этой версии исходники и документы сохраняются в Git; если позже появятся новые незакоммиченные изменения, их нужно перенести дополнительно.
- Lock-файлы зависимостей и `global.json`.
- При необходимости — собственный JSON-экспорт дневника отдельным приватным файлом. Для разработки использовать синтетические фикстуры, не этот экспорт.
- Не нужны Windows `node_modules`, `bin`, `obj`, `deploy` и сборки; зависимости установить заново на Mac.
- Не переносить приватные ключи/пароли через репозиторий. Если потребуется доступ к серверу, настроить его отдельно.

## Первые проверяемые результаты

1. Установлены точные версии macOS/Xcode/iOS/watchOS и модель часов.
2. Personal Team действительно подписывает минимальную сборку для физических часов.
3. Приложение запускается без debugger и сохраняет данные после повторного Run поверх установки.
4. Зафиксированы фактические ограничения уведомлений и срок подписи.
5. Только затем начата реализация управления реальной сессией.

Полный источник решений и критериев готовности: [план реализации](apple-watch-plan.md).
