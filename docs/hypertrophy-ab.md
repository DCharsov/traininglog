# Гипертрофия — всё тело А/Б, содержимое 1

Добавлен отдельный личный seed `personal-hypertrophy-ab`, `contentRevision = 1`.
Исходный приложенный `TrainingLog_Hypertrophy_AB_Program_v1.json` не обнаружен в рабочей папке: данные перенесены из задания от 14 сентября 2026. Числовые пробные ориентиры хранятся в редактируемых подсказках, отдельно от результатов. Импорт старых подходов не производится.

## Как использовать

1. На экране «Сегодня» или «Программа», вне активной тренировки, нажать «Добавить личный шаблон А/Б».
2. В «Текущая программа» явно выбрать «Гипертрофия — всё тело А/Б». Импорт сам выбор не меняет. Выбор сохраняется в этом браузере.
3. В «Программа» можно менять упражнения, подходы, повторы, отдых и заметки. Начальный объём: А — 14, Б — 16 рабочих подходов. Необязательный кор хранится последней строкой каждого дня, но не включается в основной объём.
4. Настроить конкретное оборудование. Для жима ногами сначала создать профиль в «Настройки → Оборудование», выбрать режим стека либо «Блины на тренажёре, платформа не учтена», затем выбрать профиль в программе или текущей тренировке. До выбора режима подтвердить подход жима ногами нельзя. Выбор в текущем занятии меняет только его снимок. Массу платформы и доступные деления приложение не придумывает.
5. Начать А или Б. После первого завершённого дня каждого типа за местную календарную неделю кор повторно не предлагается; при первом запуске добавляется только с согласия. Один подход кора включает обе стороны, отдых не задан. Подходы пустые; фактические результаты появляются после «Готово».

## Ручные этапы и ограничения

Планировщик этапов не добавлялся, как разрешено заданием. Импорт всегда начинает с двух подходов на основное упражнение. Частоту пользователь выбирает сам: сначала два занятия, затем три без одновременного повышения веса. Для основного этапа вручную установить по три подхода в первых трёх упражнениях каждого дня; остальные оставить по два. Получится А — 17, Б — 19, плюс два при включённом коре. При переходе обновить при необходимости заметки целевого RIR. Сохранение программы не меняет начатые и завершённые занятия.

Расписание и целевой RIR записаны в заметках, автоматического перехода по датам нет. Повторы обязательны; вес обязателен кроме BodyweightOnly; фактический RIR необязателен. Прогрессия — инструкция в заметках, без автоматического расчёта следующей нагрузки или диагностики усталости. Разминку можно добавить обычной строкой подхода и отметить её типом «Разминка».

Повторный импорт возвращает существующую запись, в том числе отредактированную, архивную или удалённую. Для восстановления использовать архив/корзину в настройках. Он не обновляет содержимое существующего шаблона и не сбрасывает цикл. UUID детерминированные в существующей модели с одним владельцем. Общие варианты А/Б имеют одинаковые variantId/equipmentId; отдельного справочника упражнений в приложении нет. При смене тренажёра нужно выбрать отдельный профиль, а при смене варианта — новый вариант сравнения. Настройки строк А/Б редактируются отдельно.

Клиент и API следует выпускать вместе: добавлены MachinePlatesOnly и необязательные поля seedKey/contentRevision/optionalWeekly/requiresEquipment. Старые исторические режимы не мигрируются. После отдельного разрешения владельца клиент и API опубликованы 14 сентября 2026; данные владельца не заменялись.
