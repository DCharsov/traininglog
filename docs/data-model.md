# Локальная модель v1

База `traininglog-v1`: `programs`, `sessions`, `outbox`. Версия Dexie 1. Открытие базы никогда не удаляет хранилище для восстановления после ошибки.

Program содержит дни и элементы упражнений. Элементы имеют стабильный id, variantId и equipmentId. При старте WorkoutSession получает глубокий снимок всех элементов и отдельные UUID подходов. UTC-время, локальная дата и часовой пояс фиксируются один раз.

SetRecord: draft/completed/skipped, рабочий/разминочный, строки ввода, канонические граммы и число повторений, RIR, заметка и время подтверждения. Строки ввода не участвуют в предыдущих результатах; используются только completed, working.

Каждая подтверждённая мутация — одна rw-транзакция sessions+outbox. Outbox содержит отдельный immutable snapshot. Пока транспорт отсутствует, очередь только накапливается. Черновики записываются отдельно без enqueue. Подтверждение ожидает предшествующие записи черновиков.

Эксклюзивный Web Lock удерживается вкладкой редактора. Остальные вкладки видят реактивные записи, но не могут менять базу через UI. API change поддерживает optimistic revision check; bypass -1 используется только для сериализованных операций вкладки с Web Lock.

Restore валидируется Zod и применяется атомарно, старый outbox не воспроизводится. schemaVersion экспорта независима от будущей версии сервера. На серверном этапе необходим отдельный протокол восстановления/согласования.
